# Δίγλωσσο site με ξεχωριστές σελίδες ανά γλώσσα· η σελίδα Εταιρικών Στοιχείων μόνο στα Ελληνικά

Το site είναι στατικό (HTML/CSS/JS, χωρίς build tool) και πρέπει να υποστηρίζει Ελληνικά + Αγγλικά. Αποφασίστηκε ξεχωριστό HTML αρχείο ανά γλώσσα (π.χ. `/index.html` και `/en/index.html`) αντί για ένα αρχείο με JS toggle, γιατί δίνει καθαρό SEO ανά γλώσσα χωρίς πρόσθετη λογική μετάφρασης σε JS — κόστος είναι διπλασιασμός markup ανά σελίδα, αποδεκτό σε site 4 σελίδων.

Η σελίδα Εταιρικών Στοιχείων (νομική/ΓΕΜΗ πληροφορία, άρθρο 47 §2 Ν.4072/2012) δημοσιεύεται μόνο στα Ελληνικά, ανεξαρτήτως γλώσσας πλοήγησης — η ελληνική νομοθεσία δεν απαιτεί ούτε αναγνωρίζει επίσημα μεταφρασμένη εκδοχή, και μια μετάφραση θα εισήγαγε κίνδυνο απόκλισης από το νομικά δεσμευτικό κείμενο.
